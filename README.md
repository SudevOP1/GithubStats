# GitHub Stats Dashboard 📊

Web dashboard for visualizing and monitoring GitHub repository statistics in real-time. Perfect for hackathon repo monitoring and analytics.<br>
:link: [View Live](https://sudevop1.github.io/GithubStats)<br>

## 🚀 Quick Start

```bash
cd frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173` (or the port shown in your terminal).<br>

## ✨ Features

### 📈 Analytics & Visualization

- Interactive Commit Graph
- Repository Metadata
- Contributor Profiles
- Commit Statistics

### 🎯 Advanced Filtering & Export

- Date Range Filtering
- Real-time Updates

### 🔒 Smart Caching & Rate Limit Handling

- Local Storage Cache
- Rate Limit Recovery
- Smart Suggestions
- API Warnings
